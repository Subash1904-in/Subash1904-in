### 🚦 Traffic Violation Detection System

**Computer vision system for automated traffic violation detection.**

Detects violations such as:

* 🪖 Helmet violations
* 🏍️ Triple riding
* 🚗 Overspeeding
* 🚦 Signal jumping
* ↔️ Wrong-route violations

Includes **ANPR, violation logging, fine calculation and real-time monitoring.**

`Python` `OpenCV` `MediaPipe` `Machine Learning` `Computer Vision`

### 🖐️ Gesture Controlled Virtual Mouse

A computer-vision application that allows users to control the mouse using **hand gestures**.

Built with hand landmark detection, gesture recognition, cursor mapping and movement smoothing.

`Python` `OpenCV` `MediaPipe`
